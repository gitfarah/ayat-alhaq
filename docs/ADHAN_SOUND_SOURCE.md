# Bundled Adhan notification sound

The optional Adhan alert uses **Oración Al-Azzan.ogg**, recorded and
released into the public domain by Wikimedia Commons user B9.

- Source: https://commons.wikimedia.org/wiki/File:Oraci%C3%B3n_Al-Azzan.ogg
- License: Public domain
- Android: the original Ogg Vorbis file is bundled as `adhan.ogg`.
- iOS: a mono, 16-bit PCM WAV conversion shortened to 29 seconds is bundled
  as `adhan.wav` to stay within the native notification-sound duration limit.
